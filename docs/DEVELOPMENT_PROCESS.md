# 零析AI 转写开发过程记录

## 产品目标

零析AI 转写是一个本机优先的录屏转写与音视频转写工具，面向直播、短视频、课程回放、在线播放内容整理等场景。

核心目标：

- 录制在线播放视频内容，自动抽取声音并转写为简体中文文档。
- 上传本地短视频或音频，自动转写并输出 Markdown、TXT、DOCX。
- 支持录屏文件自动保存，降低长时间录制中断风险。
- 支持本机 Whisper 识别、本机规则整理、OpenClaw/Qwen 增强整理、本地大模型直连整理。
- 支持重复内容去重、字幕辅助参考、定时录制、按播放倍速自动计算录制时长。

## 技术架构

- 桌面端：Electron
- macOS 原生录屏：Swift + ScreenCaptureKit
- 字幕 OCR 辅助：Swift 原生工具
- 语音识别：Python + faster-whisper
- 文档输出：python-docx + Markdown/TXT
- 智能整理：
  - 本机规则整理
  - OpenClaw/Qwen CLI
  - Ollama/LM Studio/llama.cpp 等 OpenAI 兼容本地模型接口

## 本地模型问题记录

长视频或长课程内容在使用 `qwen3.5:35b-a3b-coding-nvfp4` 本地模型整理时，可能出现三次请求超时。

已验证的原因：

- Ollama 服务可访问。
- 模型 ID 存在。
- 请求已经发出，Ollama runner 会进入高负载运行。
- 失败主要来自长文本智能整理负载过高，模型没有在等待时间内返回。

后续优化方向：

- 将长文档拆分成多段分别整理，再合并总结。
- 限制传给本地模型的时间线和字幕参考长度。
- 增加“只整理正文，不带完整时间线”的轻量模式。
- 给不同模型配置不同最大上下文和超时时间。
