使用说明

录制在线播放内容

先选择“系统声音”或“外部声音”，再选择“框选范围”或“全屏录制”。点击“选择录屏范围”后调整线框，确认范围后再开始录制；悬浮条可暂停、继续、停止，主界面最小化或关闭也不应中断后台任务。

录制范围

框选模式可拖动上方移动柄，或用边角调整大小。暂停时可调整录屏范围，继续录制会按新范围采集；全屏模式下可用退出全屏回到框选模式。

定时与倍速

录制定时支持不限时、固定时长、自定义时长，也支持“按视频时长计算”。自定义时长可输入 00:30:00、30:00 或 30，软件按时分秒理解；输入原视频时长并选择 1.0 到 3.0 倍播放速度，软件会自动计算录制时长，到点停止并按设置自动转写。

上传或重新转写

“上传短视频/音频”用于导入本地文件。“重新转写”用于选择已录制的视频重新生成文档，可按当前语言、模型、字幕辅助、整理方式执行，并可选择保留新版本或覆盖重新转写结果。

字幕辅助

字幕辅助可关闭，也可自动识别视频底部字幕。开启后会把字幕识别结果作为参考信息，帮助修正语音口误、发音不清或倍速播放带来的识别误差。

重复内容去重

重复内容去重用于处理在线播放卡顿、回放、跳回开头造成的重复录制。普通去重为默认模式，只移除高度相似的重复片段；强力去重会扩大检查范围，适合重复严重的录制，但可能误删主播有意重复强调的内容。关闭后保留全部识别文本。

去重只能删除已经录到的重复内容，不能恢复因为卡顿或跳播没有录到的部分。使用 OpenClaw 或本地大模型整理时，软件会提示模型发现明显断点时标注可能存在内容缺失。

语言与模型

识别语言默认自动判断。base 更快，small 平衡速度和准确率，medium 更准但更慢；倍速较高或内容重要时，建议优先使用 small 或 medium。

智能整理

智能整理有四种模式。本机规则整理不需要额外模型，任何电脑都能用。云端大模型 API 适合长内容整理，填写兼容 OpenAI 的 API 地址、模型名称和 API Key 后点击测试模型，成功后再转写。

云端服务商可以先选预设，软件会自动填入常用 API 地址和模型示例；第三方中转平台请选择“自定义”或对应平台，然后以平台后台显示的 Base URL 与模型 ID 为准。检测失败但测试模型成功，也可以正常使用。

文档模板

文档模板会影响最终整理稿结构。直播复盘适合提取核心观点、案例、问答和成交话术；课程笔记适合沉淀知识框架；素材提取适合剪辑和短视频选题。转写完成后可点击“换模板生成”，复用已有逐字稿重新整理，不会重新跑 Whisper。

常见云端 API 地址示例：DeepSeek 可填 https://api.deepseek.com，OpenAI 可填 https://api.openai.com，通义千问、硅基流动、Moonshot、火山等填各自兼容 OpenAI 的 base URL。API Key 只保存在本机浏览器存储中，转写时通过进程环境变量传入，不写入日志、Markdown、TXT 或 DOCX。

OpenClaw/Qwen 增强整理需要安装 OpenClaw，模型栏填写 OpenClaw 可识别的模型 ID，例如 ollama/qwen3.5:35b-a3b-coding-nvfp4，命令栏可留空自动检测或手动选择 openclaw 命令文件。

本地大模型直连不经过 OpenClaw，适合只安装了 Ollama、LM Studio 或 llama.cpp server 的电脑。Ollama 默认地址是 http://127.0.0.1:11434；模型名称不是文件路径，而是 ollama list 或 /v1/models 里看到的模型 ID，例如 qwen3.5:35b-a3b-coding-nvfp4。点击“检测”会读取 /v1/models，点击“测试模型”会发送一句短测试；成功后地址和模型名称会保存在下拉选择里。

如果换电脑使用，先确认本地模型服务已启动，再复制模型名称到对应输入框。检测或测试失败时，软件会在转写时自动回退到本机规则整理，不会中断文档生成；处理报告会写明实际使用状态和失败原因。

任务与输出

任务列表显示处理状态、进度条和转录时间进度，可开始或停止转录。结果按钮可打开 Markdown、TXT、DOCX 和输出文件夹；删除任务只移除列表记录，不删除原视频或已生成文件。

命名与权限

左侧“完成后弹窗命名”默认开启，录制停止后提示命名录制文件，转写完成后提示命名输出文件夹；取消或留空会保留默认名称。首次使用可能需要授予屏幕录制、系统音频和麦克风权限。
